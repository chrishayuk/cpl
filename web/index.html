CPL

The Combined Programming Language of Cambridge and London, 1962 to 1966: the ancestor of BCPL, B and C, and never fully implemented in its day. This is the same Rust program as the command line, compiled to WebAssembly and running in your browser. Code shows the stack machine a program is compiled to, and Printed shows it as it would have looked on paper in 1966. Source, tutorial and the 1966 preprocessor.
